## 0. 已锁定的事实（实施时不要再猜）

| 事实 | 值 |
| --- | --- |
| Ech0 主时间线 | `POST {apiBase}/api/echo/query`，body `{page,pageSize}`，响应 `{code:1,msg,data:{total,items}}` |
| 分页 | page 从 1 开始，pageSize 上限 100（超出静默截断），匿名强制过滤 private |
| 正文 | `content` 是 **Markdown 源码**，上游用 markdown-it `html:false` 渲染 |
| 时间 | `created_at` 是 **Unix 秒** |
| 扩展 | `MUSIC{url}` / `VIDEO{videoId}` / `GITHUBPROJ{repoUrl}` / `WEBSITE{title,site}` / `LOCATION{placeholder,latitude,longitude}` / `TWEET{url,username,statusId}` |
| 附件 | `echo_files[].file`；`url` 可能是 `/api/files/...` 相对路径；有 `width/height`，**无 duration** |
| CORS | 全放开，浏览器可直连，**不需要 dev 代理** |
| meting | `{blogConfig.music.meting.api}?server&type=song&id` → `[{title,author,pic,url,lrc}]`（url 是 http，需重建） |
| 线上数据 | 47 条；有 GITHUBPROJ/WEBSITE/LOCATION 各 1；MUSIC/VIDEO/TWEET 与附件为 0 → 必须 mock |

## T2 ech0 → 视图模型映射（纯函数 + 单测）

## T3 音乐 URL 解析（纯函数 + 单测）

**文件**：`app/utils/memos/music.ts`、`app/utils/memos/music.test.ts`

```ts
export interface MusicLinkInfo { server: 'netease' | 'tencent' | 'apple', type: 'song' | 'playlist' | 'album', id: string }
export function parseMusicLink(url: string): MusicLinkInfo | null
export function isMetingSupported(info: MusicLinkInfo): boolean   // apple → false
export function metingMetaUrl(api: string, info: MusicLinkInfo): string
export function metingAudioUrl(api: string, info: MusicLinkInfo): string   // 复用 app/utils/meting.ts
export function metingCoverUrl(api: string, info: MusicLinkInfo): string
```

规则移植自 Ech0 `web/src/utils/other.ts:parseMusicURL`：

- `music.163.com` + `id=` + `/song|playlist`（含 `#/song`）→ `netease`
- `y.qq.com` `songDetail/xxx` 或 `songid=` → `tencent/song`；`/playlist/(\d+)` → `tencent/playlist`
- `music.apple.com` → `apple`（`isMetingSupported` 为 false，卡片降级外链）
- 其他 → `null`

单测覆盖：4 个网易云形态、3 个 QQ 形态、1 个 Apple、2 个非法输入。

## T4 正文渲染（markdown → HTML / 纯文本 + 单测）

**文件**：`app/utils/memos/markdown.ts`、`app/utils/memos/plain.ts`、`app/utils/memos/plain.test.ts`

- `markdown.ts`：懒加载 `markdown-it`（`html:false, linkify:true, breaks:true`）
  - `link_open` → `target="_blank" rel="noopener noreferrer nofollow"`
  - `image` → `loading="lazy" decoding="async"`，`src` 以 `/` 开头时拼 `apiBase`
  - 导出 `async renderMemosMarkdown(md, apiBase): Promise<string>`
- `plain.ts`：`markdownToPlainText(md)` —— 去标题井号、粗斜体、行内代码、围栏代码、图片、链接保留文字、引用符，折叠空行
- 单测只覆盖 `plain.ts`（markdown.ts 依赖外部库，用浏览器验收）

**依赖**：`pnpm-workspace.yaml` 的 `content` catalog 加 `markdown-it`，`package.json` 加 `"markdown-it": "catalog:content"` 与 dev `@types/markdown-it`。用 `nip` 或手改后 `pnpm i`。

## 风险登记（实施中若命中，回到设计稿对应小节）

| 现象 | 处理 |
| --- | --- |
| `markdown-it` 装不上（pnpm catalog 规则/镜像） | 退回 `marked` + 自写正则清洗（`html` 输出需额外过滤） |
| 生产构建把 mock 打进 bundle | 用 `import.meta.dev` 守卫 + 动态 `import()`，检查产物字符串 |
| ech0 `content` 里出现相对图片路径 | `markdown.ts` 的 image 规则已拼 `apiBase` |
| 音乐卡 `audio` 因 http 直链被混合内容拦截 | 一律用 `metingApiUrl` 重建 https 地址，不照抄返回的 `url` |
| 首屏被 6 类外部请求拖慢 | 扩展卡全部 `defineAsyncComponent`，GitHub/OSM/embed 仅在可见或点击时请求 |
