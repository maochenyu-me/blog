欢迎交换友链。请通过 GitHub Issue 提交申请，机器人会自动预检，并给出可直接录入的条目。

[➡️ 点此提交友链申请](https://github.com/maochenyu-me/blog/issues/new?template=link-application.yml)

## 基本要求

1. 遵守中国大陆法律法规，不发布违法违规、侵权内容。
2. 有持续维护博客的决心：已有至少 8 篇文章，且建站满 3 个月以上。
3. 不接受纯广告、采集、搬运站点；适度的广告与赞助可以接受。
4. 免费域名（如 `github.io`、`pages.dev`、`vercel.app`）可以接受，但过于冷门、稳定性无保障的免费域名不予收录。
5. 已添加本站为友链（非硬性要求，但会优先通过）。

> 完整条款以申请表单中的勾选项为准（必须全部勾选才能提交）。本站友链统一使用 HTTPS。

## 申请之后

1. 机器人自动预检：站点能否访问、是否启用 HTTPS、订阅源能否解析、文章数与建站时长、域名类型。**只作提示，不自动拒绝**。
2. 填完后请**自行关闭 issue** 表示提交完成，评论区会贴出可直接粘贴到 `app/feeds.ts` 的条目。
3. 管理员审核后收录。站点长期失联或信息失效时，issue 会被重新打开说明原因。

本站信息见上方「我的博客信息」页签。
